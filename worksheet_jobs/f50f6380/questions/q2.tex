\begin{question}
\noindent A history student is organising books on space exploration for a library display.

The number of books on one shelf is $5x - 3$.\\
The number of books on another shelf is $3x + 9$.

Given that both shelves hold the same number of books, work out the value of $x$.
\vspace{4cm}
\answereq{x}{2}
\end{question}
